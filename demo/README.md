# Demo

A reproducible end-to-end run that never touches your real AI tool folders.

```bash
python demo/run_demo.py           # run and clean up
python demo/run_demo.py --keep    # keep the sandbox and print its path
```

## What it does

1. Creates a temporary central library and fake home directories for **all six** tools
   (`DSH`, `Codex`, `Claude`, `Gemini`, `Cursor`, `Copilot`), by setting `AEM_HOME` and the
   `AEM_AGENT_HOME_<ID>` overrides. Your `~/.claude`, `~/.codex`, … are never read or written.
2. `aem init` and `aem doctor` — a healthy, empty library.
3. Builds a small valid skill (`SKILL.md` + `scripts/greet.py`) and imports it.
4. Distributes it to Claude Code, Codex and Cursor with one command.
5. Verifies all three copies with SHA-256 tree hashes.
6. Edits the Claude copy by hand and shows `aem status` reporting `changed`.
7. Imports an updated upstream version, making the Claude copy a genuine **state C** (both sides
   changed) — the next distribute reports `conflict [C]` and writes nothing.
8. Exits with the real transcript in [demo-output.txt](demo-output.txt).

The demo is also a smoke test: it fails loudly if any exit code differs from the expected one
(including the expected `2` for the conflict step).

## Captured transcript

[demo-output.txt](demo-output.txt) is generated by the latest run on Windows with Python 3.14.4.
Machine-specific lines (absolute temporary paths, detected CLI versions) will differ on your
machine; the shape of the output is the same.
